# amazon-ecommerce-performance-sentiment-analysis
End-to-end EDA project analyzing Amazon e-commerce performance and customer sentiment using Python.
Amazon E-commerce Performance & Customer Sentiment Analysis

Project Overview

This project performs exploratory data analysis on Amazon e-commerce data to evaluate business performance, customer behavior, product trends, ratings, reviews, and customer sentiment.

Objectives

Analyze sales and revenue performance
Identify top-performing products/categories
Analyze customer ratings and reviews
Understand customer sentiment
Identify patterns in customer feedback
Generate actionable business insights
